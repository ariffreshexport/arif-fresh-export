Free publishing:
1. Create a free account on GitHub.
2. Create a new public repository, for example: arif-fresh-export.
3. Upload index.html to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. GitHub will provide a public website address after publishing.
